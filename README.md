# M218-WiiM-Bridge – Firmware

Hier werden die Firmware-Versionen der **M218-WiiM-Bridge** veröffentlicht. Die Bridge verbindet die Wandbedienung Revox M218 mit einem WiiM-Streamer.

## Update installieren

Die Bridge prüft einmal täglich selbst, ob hier eine neue Version liegt.

1. Einstellungsseite der Bridge öffnen: `http://m218.local` und den Raum antippen, oder direkt `http://m218-<raum>.local/m218`.
2. Im Abschnitt **Firmware** auf **Nach Update suchen** und danach auf **Update installieren** tippen.
3. Die LED blinkt während des Downloads. Danach startet die Bridge neu. WLAN, Raum, WiiM und Tastenbelegung bleiben erhalten.

Ohne Internetzugang der Bridge: Die `.bin`-Datei des gewünschten Releases herunterladen und unter `http://<bridge>/update` hochladen.
